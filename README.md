# HarborOps Fleet Copilot

HarborOps Fleet Copilot is a pitch-ready Node demo for a voice-first maritime operations plugin spanning PMS, defects, inventory, requisitions, and procurement follow-up.

## Run locally

```bash
npm start
```

Then open:

```text
http://localhost:3000
```

## Included

- `server.js` - mock orchestration API and static app server
- `pitch_demo/` - interactive demo frontend
- `PRODUCT_PRD_HARBOROPS_FLEET_COPILOT.md` - product requirements document
- `.github/workflows/deploy-railway.yml` - GitHub Actions deployment workflow
- `railway.json` - Railway deployment configuration
